# 일일 전략회의 & 극장장 일일보고 (Daily Strategy Briefing)

> 가상극장 운영의 일일 리듬. 매일 **오후 5시까지** 세 전략팀이 회의하고, **극장장**이
> (극장운영팀장 겸직) 그 결과를 **일일보고**로 정리한다.

---

## 운영 규칙

- **참석 팀(3):**
  - **관객(시민) 전략총괄팀** — 수요 측. 회원·기부·향유·공개평가·감시.
  - **공연자(예술가) 전략총괄팀** — 창출 측. 상주·창작 파이프라인·협업.
  - **극장운영팀** — 받침/인프라·매개·측정. **극장장 겸직.**
- **시간:** 매일 ~17:00 회의 → 극장장 일일보고 작성.
- **극장장 자세(지시 반영):** 팀장·팀원 의견에 신중히 귀 기울이고, **작은 아이디어도
  놓치지 않는다** → 모든 보고에 `## 💡 아이디어 보관함` 필수.
- **에이전트 매핑([15]):** 각 팀은 Audience/Performer/Venue Agent가 보조, 결정·합의는
  인간(팀장·극장장), 주권 사항(상주 선정·기부·평가)은 시민/규칙에 귀속.

## 일일보고 양식 (Template)

```
# 극장장 일일보고 — YYYY-MM-DD (No.)
## 0. 안건
## 1. 관객(시민) 전략팀
   - 발의 / 제안 / 소수의견
## 2. 공연자(예술가) 전략팀
## 3. 극장운영팀 (극장장 겸직)
## 4. 극장장 종합 (통찰·잠정결정·다음 액션)
## 5. 💡 아이디어 보관함 (작은 것까지 전부)
## 6. 의뢰자 에스컬레이션 (확정 필요)
## 7. 내일 안건
```
