## 1. 단계 개요 (Phases)

| 단계 | 목표 | 핵심 산출물 | 기간(가설) |
|------|------|-------------|-----------|
| **Phase 0** | 기획 확정·검증·파일럿 준비 | 확정 기획안, 트윈 데이터 표준안, 협력 극장 MOU, PoC | ~6주 |
| **Phase 1** | MVP — 시연·검증·향유 최소고리 | 시연 에디터 + 트윈 1~3개관 + 안전/예산 검증 + 향유 뷰어 | ~12–16주 |
| **Phase 2** | 정밀화·협업·라이브 | 사이트라인·정밀 시뮬, 라이더 매칭, 라이브/하이브리드, 지원사업 패키지 | ~12주 |
| **Phase 3** | 확장·다기관·스케일 | 정밀 물리/구조 시뮬, 실연-시연 보정, 다기관 연동, 트윈/에셋 공유 | 지속 |

> 기간은 가설. 공공·기관 파일럿 일정에 종속되므로 유연 조정.

**목표:** "빈 화면에서 시작하지 않게" 기획·데이터·파트너를 정렬.

체크리스트:
- [ ] 본 기획안(00~06) 내부 리뷰 — 의뢰자(도메인 전문가) 검수
- [ ] [DECISIONS.md] 미결 의사결정 기입 (브랜드명/4축 우선순위/안전책임범위/MVP범위)
- [ ] **극장 디지털 트윈 데이터 표준안** 초안 (무대치수·플라이·사이트라인 스키마)
- [ ] **파일럿 협력 극장 1~3개관** 접촉·MOU (실측·도면 확보)

- [ ] 기술 PoC: ①트윈 정규화 ②규칙기반 안전점검 ③브라우저 시연 성능
- [ ] 구글 드라이브 기존 산출물 → 본 기획안 기준 **매핑표** 작성(승인 후 착수)
- [ ] MVP 범위·성공기준 잠금

## 3. Phase 1 — MVP (핵심 가치 증명)

**MVP 한 문장:** "예술가가 한 작품을 가상시연으로 구성해, 협력 극장 디지털
트윈에 얹어 구현가능성·안전성·예산을 기본 검증하고, 시민이 무설치로 사전
체험할 수 있다."

포함(Must):
- 가상시연 에디터(무대·조명·음향·영상·동선·큐시트)
- 극장 디지털 트윈 1~3개관 적용
- 구현가능성(전환·간섭) + **안전성**(하중·동선) 규칙기반 기본 검증
- 예산 시뮬레이션 리포트(자원→예산 매핑)
- 시민 향유 뷰어(무설치 사전 체험 + 좌석 시야 기초)
- 4주체 역할 기반 협업·권한

제외(다음 단계): 정밀 물리 시뮬, 라이브 송출, 외부 예매·정산, 실연 보정.

성공 기준(예):
- 파일럿 협력 극장에서 **실제 1편**을 시연→검증→향유까지 완주
- 극장 기술팀이 "검증 결과가 현장 판단에 유효하다" 확인
- 공공/재단 담당자가 "예산·심사 자료로 쓸 만하다" 확인
- 시민 사전 체험 도달·피드백 수집

## 4. Phase 2 — 정밀화 · 협업 · 라이브

- 좌석별 사이트라인, 정밀 안전/하중 시뮬
- 테크니컬 라이더 매칭, 대관·일정 고도화
- 작품성·대중성 리뷰 워크스페이스, 지원사업 제출 패키지
- 라이브/하이브리드 향유(WebRTC SFU), 다국어 자막

## 5. Phase 3 — 확장 · 다기관 · 스케일

- 정밀 물리/구조 시뮬, 특수효과 안전 고도화
- 실연-시연 실측 보정(데이터 환류)
- 다기관(재단·공공) 연동, 극장 트윈/에셋 공유 생태계
- 글로벌 다국어·교류 공연 지원
