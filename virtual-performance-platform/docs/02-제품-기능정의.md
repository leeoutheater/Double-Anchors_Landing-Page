# 02. 제품 · 기능 정의 — 공연예술 가상시연 통합 플랫폼

문서버전: Draft v0.2 (비전 재정의 반영)

> 기능은 **생애주기(기획→제작→운영→향유)** 와 **4주체** 두 축으로 정의한다.
> 개념: [00-비전과개념.md] · 주체 니즈: [06-이해관계자맵.md]

---

## 1. 제품 한 문장

같은 디지털 시연본을, 예술가는 창작하고, 극장은 검증하고, 공공기관은 심사하며,
시민은 누리는 — 공연예술 가상시연 통합 워크스페이스.

## 2. 생애주기별 기능 (Lifecycle Features)

### 2.1 기획 (Planning)
- **작품 컨셉 시각화:** 무대 스케치, 레퍼런스 보드, 컨셉 시연 초안
- **작품성·대중성 사전 검토:** 시연본 기반 전문가 리뷰·시민 사전 피드백
- **예산 시뮬레이션:** 시연에서 도출된 자원(인력·장비·시간)→예산 초안 자동 산출
- **지원사업 자료 생성:** 심사용 시연 영상·예산 근거·기획서 첨부 패키지

### 2.2 제작 (Production)
- **가상시연 에디터:** 무대·조명·음향·영상·출연·동선을 시간축(큐시트)에 구성
- **극장 디지털 트윈 적용:** 실제 극장 모델 위에 작품을 얹어 시연
- **구현가능성 검증:** 무대기계 전환 시퀀스/전환 시간, 조명·음향·영상 사양 점검
- **안전성 시뮬레이션:** 플라이·리깅 하중, 구조 하중, 동선·비상동선, 특수효과 안전구역
- **협업 리허설:** 4주체 역할별 동시 참여, 코멘트·버전 스냅샷

### 2.3 운영 (Operation)
- **일정·대관 관리:** 극장 일정, 테크니컬 라이더 매칭, 셋업·리허설·공연 일정
- **자원·인력 운용:** 시연 기반 인력·장비 콜시트, 예산 집행 추적
- **실연-시연 보정:** 실제 공연 데이터로 시연본 실측 보정(다음 작품에 환류)
- **기록·아카이브:** 시연·실연 기록의 표준 아카이브화

### 2.4 향유 (Enjoyment / Citizen Access)
- **시민 향유 뷰어:** 무설치 사전 체험, 다국어 자막
- **좌석·접근성 정보:** 좌석별 사이트라인 미리보기, 배리어프리 정보
- **예매 연계:** 외부 예매 연동, 사전 관심·알림
- **참여·피드백:** 시민 피드백→작품·정책 환류, 하이브리드 관람

## 3. 4주체별 핵심 기능 뷰 (Role-based Views)

> **단일 데이터, 다중 뷰.** 같은 시연본을 역할에 따라 다르게 본다.

| 주체 | 주요 뷰 | 핵심 기능 |
|------|---------|-----------|
| 공연자 | 창작 뷰 | 시연 에디터, 동선·큐시트, 협업 리뷰, 시연본 공유 |
| 극장운영자 | 기술·안전 뷰 | 디지털 트윈 검증, 무대기계/사이트라인, 안전 시뮬, 라이더 매칭, 대관 |
| 공공기관 | 예산·성과 뷰 | 심사 자료, 예산 시뮬 리포트, 진행·성과 추적, 향유·접근성 지표 |
| 관객 | 향유 뷰 | 사전 체험, 좌석 시야, 접근성, 예매, 피드백 |

## 4. 핵심 검증 기능 상세 (Validation Features)

### ① 작품성 × 대중성
- 시연본 리뷰 워크스페이스(전문가 평가 루브릭 + 시민 사전 반응 수집)
- 관심도·선호 데이터 집계 → 작품 보완·홍보 전략 입력값

### ② 구현가능성 × 안전성 (도메인 핵심)
- **극장 시스템 검증:** 무대 치수/프로시니엄/윙/그리드, 객석 사이트라인
- **무대기계·전환:** 바텐(배튼) 배치·하중, 전환 시퀀스·전환 시간 타당성
- **공연기술:** 조명 채널·포지션, 음향 배치·SPL 가늠, 영상 프로젝션/LED 매핑
- **안전:** 하중 한계 경고, 동선·비상동선·군중 안전, 특수효과 안전구역
- ⚠️ **범위:** 의사결정 보조용 시뮬레이션. 공식 구조·안전 인증을 대체하지 않음.

### ③ 기획·예산 타당성
- 시연 구성요소 → 자원 산정 → 예산 항목 자동 매핑(인력·장비·대관·제작비)
- 시나리오별 예산 비교, 지원사업 심사·책무성 리포트

### ④ 홍보 기반
- 시연본에서 티저·키비주얼·예고편 추출
- 시민 사전 소통 페이지(체험+접근성+예매) 자동 구성

## 5. 정보 구조 (Information Architecture)

```
대시보드 (역할별 진입)
├─ 작품(프로젝트)
│   ├─ 기획 (컨셉·작품성/대중성·예산 시뮬)
│   ├─ 가상시연 에디터 (무대·조명·음향·영상·동선·큐시트)
│   ├─ 극장 적용 (디지털 트윈 선택·구현가능성·안전성)
│   ├─ 협업·리뷰
│   └─ 발행 (향유 페이지·홍보 자산·아카이브)
├─ 극장 디지털 트윈 라이브러리
├─ 에셋 라이브러리 (무대·조명·음향·영상·출연)
├─ 운영 (일정·대관·예산·인력)
├─ 공공/사업 (지원·심사·성과·책무성 리포트)
├─ 시민 향유 (공개 체험·예매·접근성·피드백)
└─ 설정 (조직·역할/권한·언어)
```

## 6. 우선순위 (MoSCoW)

| 우선순위 | 기능 |
|----------|------|
| **Must** | 가상시연 에디터, 극장 디지털 트윈(파일럿), 구현가능성·**안전성** 기본 검증, 예산 시뮬 리포트, 시민 향유 뷰어, 역할 기반 협업 |
| **Should** | 사이트라인 미리보기, 테크니컬 라이더 매칭, 작품성/대중성 리뷰, 지원사업 패키지, 다국어 |
| **Could** | 실연-시연 실측 보정, 하이브리드 관람, 에셋/트윈 공유 마켓, 외부 예매 연동 |
| **Won't(초기)** | 공식 안전 인증, 자체 결제망, 풀 3D 모델링, VR 전용 클라이언트 |

## 7. 비기능 요구사항 (NFR)

- **정합성:** 무대기술·극장건축 실제 규격·안전기준 반영(전문가 검수 루프)
- **단일데이터/다중뷰:** 역할별 뷰 분기, RBAC
- **접근성:** 무설치·모바일·배리어프리, 다국어 i18n 기본
- **성능:** 표준 환경 시연 프리뷰 30fps, 시뮬레이션은 정확도/속도 단계 제공
- **추적성:** 의사결정·예산·검증 이력 기록(공공 책무성)
