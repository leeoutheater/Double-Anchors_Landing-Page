# 02. 제품 · 기능 정의 — 가상공연제작 웹플랫폼

## 1. 핵심 사용자 여정 (Core User Journey)

```
[1] 가입/온보딩 → [2] 공연 프로젝트 생성 → [3] 무대 구성 →
[4] 출연자/아바타 설정 → [5] 음향·연출 동기화 → [6] 리허설/프리뷰 →
[7] 라이브 송출 또는 사전녹화 발행 → [8] 관객 참여(채팅·후원) →
[9] VOD 아카이브 → [10] 정산·인사이트
```

핵심 약속: **"첫 공연을 1일 안에 송출"** — 템플릿과 AI 보조로 빈 화면에서
시작하지 않게 한다.

## 2. 기능 영역 (Feature Areas)

### 2.1 무대 에디터 (Stage Editor)
- 템플릿 기반 무대(콘서트홀, 클럽, 야외, 추상공간 등) 선택·편집
- 카메라 앵글·무빙(키프레임), 조명·파티클·배경 영상(LED 월 효과)
- 외부 3D 에셋(glTF/GLB) 임포트, 2D 영상/이미지 레이어
- **AI 무대 생성**: 텍스트 프롬프트 → 무대 분위기/배경 초안 생성

### 2.2 출연자 & 아바타 (Performers & Avatars)
- 아바타 임포트(VRM 등 표준 포맷), 프리셋 아바타 라이브러리
- **영상→모션**: 웹캠/영상에서 동작 추출하여 아바타에 매핑
- 실시간 립싱크/표정(오디오 기반), 의상·소품 커스터마이즈
- 다중 출연자 배치 및 동선 설정

### 2.3 음향 & 연출 동기화 (Audio & Sequencing)
- 음원 업로드·타임라인 배치, 비트/큐 마커
- 조명·카메라·이펙트를 음악 타임라인에 동기화(큐시트)
- 라이브 모드: 실시간 큐 트리거(오퍼레이터 콘솔)

### 2.4 리허설 & 협업 (Rehearsal & Collaboration)
- 실시간 공동 편집(역할: 연출/디자이너/오퍼레이터/뷰어)
- 버전 스냅샷·롤백, 코멘트/리뷰
- 프리뷰 송출(비공개 링크)로 관계자 리허설

### 2.5 송출 & 배포 (Broadcast & Distribution)
- 라이브 스트리밍(저지연) / 사전녹화 렌더 후 발행
- 외부 채널 동시송출(유튜브/트위치 등 RTMP) 옵션
- 품질 단계(절전/표준/고품질) 선택으로 디바이스 대응

### 2.6 관객 경험 (Audience Experience)
- 무설치 관람(웹 링크), 다국어 자막
- 실시간 채팅·이모지·후원(도네이션)·신청곡/투표 등 인터랙션
- 티켓 게이트(무료/유료/초대코드)

### 2.7 수익화 & 정산 (Monetization)
- 티켓 판매, 후원, VOD 유료 열람, 에셋 마켓
- 정산 대시보드, PG/결제 연동
- 매출·관객·체류시간 인사이트 분석

### 2.8 아카이브 (Archive / VOD)
- 공연 자동 녹화·VOD 변환, 챕터/하이라이트
- 다국어 자막 자동 생성·번역
- 공개/비공개/유료 설정, 임베드 링크

## 3. 기능 우선순위 (MoSCoW)

| 우선순위 | 기능 |
|----------|------|
| **Must** | 무대 템플릿 에디터, 아바타 임포트, 음향 타임라인, 사전녹화 발행, 관객 관람+채팅, VOD 아카이브 |
| **Should** | AI 무대 생성, 영상→모션, 라이브 저지연 송출, 후원/티켓, 다국어 자막 |
| **Could** | 외부 동시송출, 에셋 마켓, 실시간 공동편집, 투표/신청곡 |
| **Won't(초기)** | VR 전용 클라이언트, 풀 3D 모델링, 고급 물리엔진, 자체 결제망 |

## 4. 정보 구조 (Information Architecture)

```
대시보드
├─ 내 공연 (프로젝트 목록)
│   └─ 프로젝트
│       ├─ 무대 에디터
│       ├─ 출연자/아바타
│       ├─ 음향/큐시트
│       ├─ 리허설/프리뷰
│       ├─ 송출 설정
│       └─ 발행/아카이브
├─ 에셋 라이브러리 (무대/아바타/음원/이펙트)
├─ 관객·티켓 관리
├─ 수익/정산
└─ 설정 (팀/권한/결제/언어)
```

## 5. 비기능 요구사항 (NFR)

- **성능:** 표준 노트북/웹에서 30fps 프리뷰, 송출 시 끊김 최소화
- **접근성:** 무설치, 모바일 관람 지원, 다국어(국문 기본 + 다국어 확장)
- **안정성:** 라이브 송출 중 장애 복구(재연결, 폴백 스트림)
- **보안/권한:** 프로젝트별 역할 기반 접근제어(RBAC)
- **국제화:** UI·자막 i18n 구조 기본 내장
