# 12. 대형 블랙박스 극장 — 설계 브리프 (Large Black Box Theatre · Design Brief)

문서버전: Draft v0.1 · 작성기준일: 2026-06-01

> 본 문서는 **의뢰자(30년 공연학·무대기술·극장건축 경험)가 직접 수행할 3D 모델링**을
> 위한 *요구·파라미터 정의서 + 모델링 컨벤션 가이드*다. 건축적 판단과 수치는 **의뢰자
> 확정**이며, 본 문서는 구조·표준·플랫폼 정합을 보조한다.
>
> ⚠️ **모든 치수·수량은 placeholder(의뢰자 확정 대기)**. 기존 BLACKBOX 모델 제원은
> 의뢰자 재확인 중이므로 본 문서에 수치로 적용하지 않는다.

---

## 0. 목적 · 위치

- 가천대(아츠칼리지) 소규모 트윈이 **수용하지 못하는 대규모 공연**을 검증할 수 있는
  **대형 블랙박스 메타극장** 레퍼런스 트윈을 신규 모델링한다.
- 접근: 백지가 아니라 **기존 LEEOU_THEATER 형식 생성기(`build_format_3dm.py`) 위에
  '대형(LARGE)' 클래스를 추가**하는 방향(§4). [11] 매칭 엔진의 대규모 기준선이 된다.

## 1. 설계 목표 (Design Goals)

1. **무한·가변 공연형식 수용(블랙박스 메타극장):** 6형식(블랙박스·프로시니엄·
   돌출·원형·가로지름·양면) + **사용자 정의 변형**을 단일 공간에서 전환.
2. **대규모 수용:** 대형 객석·대형 무대·고(高)그리드·대(大)하중 — 소규모 트윈의 한계
   극복.
3. **검증 친화:** 구현가능성·안전성·사이트라인 시뮬레이션([00] 검증)에 바로 쓰이는
   데이터 구조로 모델링.

## 3. 가변성 메커니즘 (Transformability)

대형이면서 **형식 전환**이 가능해야 블랙박스 메타극장이 된다.

- **가변 객석:** 텔레스코픽/리트랙터블 좌석, 객석 왜건, 가변 단
- **가변 무대:** 모듈 데크(승강/조립), 무대 왜건, 트랩
- **가변 리깅:** 전(全) 천장 모터리깅 그리드로 형식별 배튼·막 재배치
- **형식 전환 시나리오:** 블랙박스 ↔ 프로시니엄 ↔ 돌출 ↔ 원형 ↔ 가로지름 ↔ 양면
  (각 전환의 객석·무대·동선·리깅 구성 정의 — 의뢰자 시나리오)

## 4. 파라메트릭 모델링 가이드 (Rhino/Grasshopper — 플랫폼 정합)

기존 자산과 **일관**되게 모델링하면 매칭·검증·변환 파이프라인에 바로 올라간다.

- **레이어 컨벤션 계승(필수):** 기존 BLACKBOX 모델의 레이어 체계를 따른다 —
  `3D_STRUCTURE_*`(WALL/COLUMN/CEILING/H-BEAM/BOTTOM_*),
  `3D_STRUCTURE_PIPE_GRID_*`(그리드), `3D_STRUCTURE_CATWALK_*`,
  `BLACKBOX_STAGE_DECK*&SUPPORT*`, `STRUCTURE_Proscenium_PL`, `STRUCTURE_CEN_PL`.
  → 일관된 레이어 = 자동 태깅·매칭·안전검증 가능.
- **극장기준점·절대좌표:** 0,0,0 기준점·절대좌표로 모델링(L1 '극장기준점' 기능과 정합).
- **단위·정밀도:** mm, absolute tolerance(기존 0.01 수준) — 의뢰자 확인.
- **태깅 규칙:** `*_tagged` 모델 컨벤션을 따라 형식·요소 메타데이터 부여
  (매칭·검증·MVR/GDTF 변환에 사용).
- **생성기 확장:** `build_format_3dm.py` / `build_common_3dm.py`에 **'LARGE' 형식
  클래스**를 추가해, COMMON 베이스에서 대형 6형식을 파라메트릭 생성하는 경로 권장.
- **렌더 메시 저장:** L1 뷰어 표시 위해 저장 시 렌더 메시 포함(없으면 [09] Brep 이슈
  재현). 또는 Compute 메싱 경로.

## 5. 검증 연계 (Validation Hooks)

모델이 다음 검증에 바로 쓰이도록 데이터를 갖춘다.

- **안전성(참고용):** 그리드·바텐 하중 → Braceworks 류 하중 검증([00]②, [08]).
- **사이트라인:** 가변 객석 형식별 좌석 가시선([10] 향유 미리보기와 공유).
- **구현가능성:** 무대전환·반입·동선 시간/충돌.
- **출력:** .3dm(원본) → glTF(뷰어)/MVR·GDTF(조명·VW) → 트윈 등록([11]).

## 6. 산출물 (Deliverables)

1. `LARGE_BLACKBOX_*.3dm`(레이어·태깅 컨벤션 준수)
2. 형식 변환 정의(6형식 + 사용자정의)
3. 트윈 메타(객석·치수·그리드·하중·안전) → [11] TheaterProfile 등록
