# 07. 확장 개념 — 운영조직 · 블랙박스 메타극장 · 공론의 장

문서버전: Draft v0.3 · 개념 확장 (의뢰자 정의 반영)

> [00-비전과개념.md]·[06-이해관계자맵.md]를 확장하는 문서. 플랫폼을 단순 '제작
> 도구'에서 **운영되는 가상극장 조직 + 공공 검증·향유의 장**으로 격상한다.

---

## 1. 플랫폼 = 가상 공연제작 운영조직 (Producing-House Model)

플랫폼은 도구의 집합이 아니라, **상설 공연단체를 보유한 공연제작 조직(producing
house)처럼 작동**한다. 실제 공연장의 운영·조직 개념을 디지털로 차용한다.

- **상주단체 개념:** 플랫폼에 입주한 공연단체·예술가가 마치 극장의 *상주단체*처럼
  시즌·레퍼토리·제작 사이클을 운영
- **조직 역할 내장:** 예술감독·프로듀서·무대감독·조명/음향/영상/무대 디자이너·
  제작PD·운영 등 실제 극장 조직의 역할이 플랫폼 권한·워크플로우로 구현
- **운영 개념:** 시즌 편성, 대관·일정, 제작 회의, 콜시트, 정산이 조직 운영처럼 흐름
- **의미:** "한 번 쓰는 시뮬레이터"가 아니라 **지속 운영되는 가상극장**

> 기존 자산의 미착수 계층 **L7(운영 통합)** 이 바로 이 개념의 구현부다.

## 2. 블랙박스 메타극장 (Black Box Meta-space)

극장은 **무한히 재구성 가능한 블랙박스**로, 가상의 무한한 공연형식을 수용한다.

- **가변 무대형식:** End-stage · Thrust(돌출) · In-the-round(원형) · Traverse(가로지름)
  · Promenade(산책형) + **사용자 정의 변형 공간** (기존 설계 NOTE의 요구사항)
- **메타공간:** 어떤 극장 디지털 트윈도 로드하고, 비정형·실험적 공간도 생성
- **좌표 기반:** *극장기준점·절대좌표*로 공간을 통제 (기존 L1 '극장기준점' 기능과 직결)
- **무한 형식 수용:** 프로시니엄부터 환경연극·이머시브까지 하나의 메타공간에서

> 기존 자산의 '가변 무대형식 + 극장기준점 + 절대좌표 편집'을 **메타극장 개념으로
> 일반화**한 것.

## 3. 공론(公論)의 장 (Public Forum for Validation)

극장은 동시에, **지원사업에 공모한 단체·예술가가 작품의 계획안과 구현가능성을
검증하는 공론의 장**이다.

- **공개 검증:** 4주체가 같은 시연본을 두고 공개적으로 검토·질의·보완
- **심의 투명성:** 지원 심사가 밀실이 아니라 시연 기반 공개 토론으로
- **동료 평가(peer review):** 예술가·기술가·기관·시민이 함께 타당성을 따짐
- **책무성 직결:** 공론의 기록이 곧 공공 예산의 책무성 근거

> [06-이해관계자맵]의 '예술가→공공기관' 흐름을 **공개된 심의 광장**으로 구체화.

## 4. 시연 기반 홍보 (Promotion Begins with the Pre-visualization)

홍보는 완성된 공연이 아니라 **시연에서 본격적으로 시작**된다.

- 시연본 → 티저·예고·키비주얼·관심도 측정 → **제작과 병행하는 마케팅**
- 완성 전에 관객이 형성되고, 예매·후원·기대가 제작을 추동
- [00]의 '검증=홍보' 원칙의 실행 메커니즘

## 5. 개방형 과정 관극 (Open-Process Spectatorship)

관객(시민)은 **공연의 연습과정부터 시연까지 전 과정을 참관**할 수 있다.

- 완성된 결과만이 아니라 **만들어지는 과정**이 콘텐츠이자 교육이자 아카이브
- 시민이 창작 과정을 지켜보고, 사전 피드백으로 개입·참여
- **기존 프로젝트의 핵심 철학과 정확히 수렴:**

  > "결과물(공연)이 아니라 **제작 과정 그 자체를 가상화 및 자료화**" — 기존 설계 NOTE

- 과정의 공개·자료화가 작품성·대중성 검증과 시민 향유를 동시에 충족

## 6. 다섯 개념의 통합 (How They Fit)

```
   누가 운영하나      어디서             어떻게 검증하나     어떻게 알리나      누가 보나
 ┌────────────┐  ┌────────────┐  ┌────────────┐  ┌────────────┐  ┌────────────┐
 │ 운영조직   │  │ 블랙박스   │  │ 공론의 장  │  │ 시연 기반  │  │ 개방형     │
 │ (상주단체) │→ │ 메타극장   │→ │ (공개 검증)│→ │ 홍보       │→ │ 과정 관극  │
 └────────────┘  └────────────┘  └────────────┘  └────────────┘  └────────────┘
        └───────────── 하나의 디지털 시연본을 관통 ─────────────┘
```

- **운영조직**이 **메타극장**에서 작품을 올리고 → **공론의 장**에서 검증받고 →
  **시연**으로 홍보를 시작하며 → 시민이 **과정부터** 관극·참여한다.
- 이 다섯 개념은 [00]의 4주체·4검증축·생애주기를 *살아 움직이는 극장 운영*으로 만든다.
