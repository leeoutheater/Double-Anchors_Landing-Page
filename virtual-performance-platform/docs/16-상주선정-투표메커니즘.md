# 16. 상주 선정 — 2라운드 투표 메커니즘 (Residency Selection)

문서버전: Draft v0.1 · 작성기준일: 2026-06-01 · 의뢰자 방향 반영

> 매월 상주 5개 작품을 선정하는 메커니즘. **시민 주권(대중 우선) + 작품성 보강**을
> 2라운드로 구현한다. [13] 공연자 상주, [14] 거버넌스, [15] Audience Agent 운영부.

---

## 0. 원칙

- **대중 우선:** 1차는 **시민 단독**(심사위원 배제) — 대중성을 먼저, 독립적으로.
- **작품성 보강:** 2차에서 심사위원이 **가점**으로 작품성을 더한다(대체가 아닌 보강).
- **투명·책무성:** 집계·규칙·결과를 공개·기록(어뷰징 방지). 결과는 가공·역전 불가.

## 1. 라운드 구조 (Two Rounds)

```
[신청·프로필 공개]
      │
 ① 1차 투표 (1개월, 시민 단독)  ─ 심사위원 참여 불가
      │   선호도 상위 작품 → shortlist (N개)
      ▼
 ② 2차 투표 (심사위원 가점 + 재투표)
      │   심사위원 작품성 가점 반영 후 재투표
      ▼
 ★ 최종 5개 작품 선정 = 그 달의 상주
      │
 [무료 / 50% 감액 적용]
```

### 1.1 1차 투표 — 시민 단독 (1개월)
- **기간:** 1개월.
- **대상:** 그 달 신청·프로필 공개된 작품.
- **참여자:** 검증된 시민(관객). **지원사업 심의 심사위원은 참여 불가.**
- **방식:** 선호도 투표(1인 1표 기준, 어뷰징·중복·봇 방지).
- **산출:** 선호도 상위 **N개** 작품을 shortlist로 2차 진출. *(N = 의뢰자 확정, 제안:
  10개)*

### 1.2 2차 투표 — 심사위원 가점 + 재투표
- **참여자:** 시민 + **심사위원**(2차부터 참여).
- **가점:** 심사위원이 작품성 평가 → shortlist 작품에 **가점** 부여.
- **재투표:** 가점이 반영된 상태에서 재투표 → 합산 점수 상위 **5개** 최종 선정.
- *(가점 산식·재투표 주체(시민만 vs 시민+심사위원)·합산 방식 = 의뢰자 확정, §4.)*

### 1.3 최종 선정 & 사용료
- **최종 5개 작품 = 그 달의 상주.**
- **무료 / 50% 감액** 적용은 작품 특성([13] D23)·최종 순위에 따라. *(매핑 규칙 =
  의뢰자 확정. 예: 시민 선호 최상위는 전액 무료, 이하 50% 등)*

## 2. 평가 철학과의 정합

| 라운드 | 반영 축 | 우리 원칙 |
|--------|---------|-----------|
| 1차 (시민 단독) | **대중성** | 대중 우선·시민 주권([00]§7·F17) |
| 2차 (심사 가점) | **작품성** | 이중축 보강(대체 아님) |

→ "대중성 먼저, 작품성으로 보강" = 소수 심사 독점의 해체이자 공정 병행.

## 3. Audience Agent 운영 책임 ([15])

- **운영(자율):** 1차/2차 투표 진행·실시간 현황·집계, 심사위원 **1차 배제 강제**,
  shortlist 산출, 2차 가점·재투표 집계, 어뷰징·중복·봇 탐지·플래그, 투명 리포트.
- **주권 경계(절대):** 결과를 **가공·역전 금지**. 최종 선정은 *집계 결과 그대로*.
- **인간 승인(HITL):** 어뷰징 *제재 확정*, 규칙 변경, 무료/50% *적용 확정*(Director 감독).

## 4. 잔여 결정 (→ DECISIONS D34)

- **N(1차 shortlist 규모)** — 제안 10개
- **가점 산식** — 심사위원 가점의 크기·정규화(예: 작품성 점수의 0~X% 가산)
- **2차 재투표 주체** — 시민만 vs 시민+심사위원 합산
- **합산·동점 처리** — 최종 점수 산식, 동점 시 규칙
- **무료/50% 매핑** — 순위·작품 특성([13] D23)과의 연결
- **시민 자격·1인1표 검증** — 어뷰징 방지 수준

## 5. 의뢰자 확인 포인트

1. 1차→2차 shortlist 규모(N)와 최종 5개 사이 비율
2. 심사위원 가점이 시민 1차 결과를 **뒤집을 수 있는 한도**(대중 우선 보호 정도)
3. 2차 재투표에 시민이 다시 참여하는지(권장: 참여 — 대중 우선 일관)
4. 무료 vs 50% 판정 규칙
