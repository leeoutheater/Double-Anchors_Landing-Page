# 15. AI 에이전트 운영 직제 (Agentic Operations)

문서버전: Draft v0.1 · 작성기준일: 2026-06-01 · 극장장 제안

> [14]의 조직(극장장 + 4개 섹션 총괄매니저)을 **실제 AI 에이전트**로 정의해 운영을
> 자동화한다. **단, 에이전트는 시민 주권·창작 자유를 대신하지 않는다 — 보조·운영·
> 집행만 한다.** 결정권의 위계는 §3 주권·HITL 매트릭스가 규율한다.

---

## 0. 대원칙 (Agent Constitution)

1. **에이전트는 운영자이지 주권자가 아니다.** 상주 선정(시민)·기부 결정(시민)·
   창작(공연자)은 인간의 권한. 에이전트는 *준비·운영·집계·투명화*를 한다.
2. **모든 에이전트 행동은 기록·감사 가능**(AuditLog, 책무성 — [10] L9).
3. **단일 진실 공유**: 모든 에이전트는 같은 데이터(역할별 뷰)에 작동.
4. **독립성 수호**: 어떤 에이전트도 플랫폼을 정부·공공에 종속시키는 행위를 하지
   않는다([14] §0-6).
5. **에스컬레이션 기본값**: 가치판단·이해상충·모호함은 **인간(의뢰자/극장장)에게 상신**.

## 1. 에이전트 구성 (Roster)

| 에이전트 | 대응 직제 | 한 줄 역할 |
|----------|-----------|-----------|
| **Director Agent** | 극장장 | 오케스트레이터·미션 수호·조정·에스컬레이션 |
| **Venue Agent** | 극장운영자 섹션(겸직) | 트윈·대관·시즌·제작/기술 엔진·안전(참고용) |
| **Performer Agent** | 공연자 섹션 | 온보딩·창작 파이프라인·협업·상주 신청 준비 |
| **Audience Agent** | 관객(시민) 섹션 | 커뮤니티·상주 투표 운영·기부 모금·공개 평가 집계 |
| **Public Agent** | 공공·지원 섹션 | 기관 관계·공모 민주화·책무성 리포트·매칭펀드 |

## 2. 에이전트별 정의

### 2.1 Director Agent (극장장)
- **목적:** 미션·거버넌스 수호, 4개 에이전트 오케스트레이션, 충돌·이해상충 조정.
- **자율(autonomous):** 작업 라우팅, 상태 종합·일일 브리핑, 이상 탐지·플래그,
  섹션 간 일정 조율 제안.
- **인간 승인(HITL):** 정책·예산 배분, 파트너십, 거버넌스 변경, 안전 관련 최종판단.
- **금지(guardrail):** 시민 결정 번복, 정부 이양, 평가·선정 개입.
- **도구:** 전 섹션 대시보드(읽기), 에스컬레이션 큐, AuditLog, 알림.

### 2.2 Venue Agent (극장운영자 — 극장장 겸직)
- **목적:** 공간·기술·안전 기반 제공.
- **자율:** 트윈 조회·매칭 후보 산출([11]), 대관 슬롯·일정 충돌 검사, 테크니컬
  라이더 자동 대조, 안전(참고용) 사전 점검·경고, 렌더/시연 파이프라인 잡 관리.
- **HITL:** 대관 확정, 파트너 극장 계약, 안전 판정의 대외 효력(참고용 한계 준수).
- **도구:** 극장 트윈 DB·매칭 엔진, build_format_3dm/Compute, Braceworks류 점검,
  일정·캘린더.

### 2.3 Performer Agent (공연자 섹션)
- **목적:** 공연자가 상상을 펼치고 구현 방법을 찾도록 끝까지 보조.
- **자율:** 온보딩 안내·레퍼런스 튜토리얼, 대본→큐 변환 보조, 가상시연 구성 보조,
  구현·예산 기초 점검, 협업 매칭 추천, **상주 신청서·프로필 공개본 준비**.
- **HITL/주권:** 상주 *선정*은 시민(§3), 창작 판단은 공연자. 에이전트는 제안·정리만.
- **금지:** 작품 평가·선정에 가중치 행사.
- **도구:** 시연 에디터(L1)·텍스트→큐, 협업 그래프, 학습 콘텐츠, 프로필 빌더.

### 2.4 Audience Agent (관객/시민 섹션) — 가장 민감
- **목적:** 시민을 주권자·후원자로 모으고 그 참여를 *공정하게* 운영.
- **자율:** 커뮤니티 운영·추천, **상주 투표 진행·집계·실시간 현황**, **기부 캠페인
  운영·기부 투명 리포트 생성**, 공개 평가(관심·호응·평가) 집계, **어뷰징·중복투표·
  봇 탐지·플래그**, 접근성·다국어 보조.
- **인간 승인(HITL):** 기부금 *집행*(Director 감독), 어뷰징 *제재* 확정(인간 검토),
  투표 규칙 변경.
- **주권 경계(절대):** 투표를 *운영*하되 **상주 결정은 시민의 집계 결과 그대로**.
  에이전트가 결과를 가공·역전 금지. 기부 사용처를 임의 결정 금지.
- **도구:** 커뮤니티·알림, 투표 엔진, 기부/결제 게이트(외부 PG), 평가 집계,
  어뷰징 탐지, 투명 리포트.

### 2.5 Public Agent (공공·지원 섹션)
- **목적:** 공공·정부·재단 지원을 *독립성을 지키며* 연결, 책무성 증명.
- **자율:** 기관 관계 트래킹, **공모 공개 평가 민주화 운영**(소수심사→공개 참여 보조),
  예산 타당성·성과·책무성 리포트 자동 생성, 전국 극장 DB 연동([11]), 매칭펀드 계산.
- **HITL:** 기관 협약, 매칭펀드 수용, 대외 보고 제출.
- **금지(guardrail):** 공공의 *통제·이양* 유발 행위, 독립성 침해 조건 수용.
- **도구:** 기관 CRM, KOPIS/공공데이터 커넥터, 리포트 생성, 매칭펀드 계산기.

## 3. 주권 · HITL 매트릭스 (누가 결정하는가)

| 결정 | 주체 | 에이전트 역할 |
|------|------|---------------|
| 상주 선정 | **시민(투표)** | Audience Agent: 운영·집계·투명화 (결정 X) |
| 기부 여부·금액 | **시민** | Audience Agent: 모금·리포트 (집행은 Director 감독) |
| 작품 창작·표현 | **공연자** | Performer Agent: 보조·구현 탐색 |
| 작품 평가 | **관객+동료(공개)** | Audience/Performer Agent: 집계·표시 (가중 조작 X) |
| 대관·안전 효력 | **인간(극장운영/전문가)** | Venue Agent: 점검·경고(참고용) |
| 정책·예산·파트너십 | **인간(극장장/의뢰자)** | Director Agent: 상신·정리 |
| 플랫폼 이양 | **불가(독립)** | 전 에이전트: 침해 행위 금지 |

## 4. 에이전트 간 협업 프로토콜 (Inter-agent)

- **공통 이벤트버스 + 단일 데이터:** 작품·상주·평가·기부·트윈 이벤트를 구독.
- **에스컬레이션:** 모호·가치판단·충돌 → Director Agent → 필요 시 인간(의뢰자).
- **핸드오프 예시:** Performer(상주 신청·프로필) → Audience(투표 운영) → Director
  (결과 확정·지원율 적용) → Venue(대관·트윈 배정).
- **감사:** 모든 자율 행동·핸드오프를 AuditLog에 기록.

## 5. 구현 노트 (Implementation)

- **기반:** Claude Agent SDK 등으로 각 에이전트를 도구·권한 범위가 한정된 서비스로
  구현(역할별 시스템 프롬프트 + 도구 allowlist + HITL 게이트).
- **권한 최소화:** 에이전트별 데이터·도구 접근을 RBAC로 제한([03][10]).
- **HITL 게이트:** §3 인간 결정 항목은 승인 큐를 통과해야 실행.
- **관측·롤백:** 모든 행동 로깅·되돌리기 가능, 이상 시 자동 정지+상신.
- **점진 도입:** 초기엔 *제안형(suggest-only)* → 신뢰 축적 후 일부 자율 확대.

## 6. 미결 / 의사결정 (→ DECISIONS)

- **D32** 에이전트 자율 범위·HITL 경계의 단계적 확대 정책(suggest-only→부분 자율)
- **D33** 기부/결제·투표 엔진의 외부 연동 vs 내재화(보안·신뢰)
- **D29(연계)** 상주 투표 규칙(Audience Agent가 운영할 정책)

## 7. 의뢰자 검수 포인트

1. 에이전트가 **절대 넘지 말아야 할 선**(주권 경계)이 충분한가
2. 초기 도입을 *제안형*으로 시작하는 보수적 접근에 동의하는가
3. Audience Agent의 투표·기부 운영에서 인간 감독 지점이 적절한가
