# 21. 크로스-OS 데이터 허브 & 동기화 (Cross-OS Data Hub)

문서버전: Draft v0.1 · 2026-06-02 · 창시자 지침: 여러 컴퓨터·여러 OS에서 진행,
맥락 끊김 방지, 각 OS 로컬 폴더 공유, **Google Drive = 데이터 허브.**

---

## 0. 원칙 — 역할 분담 (Source of Truth)

| 종류 | 단일 진실 | 이유 |
|------|-----------|------|
| **문서·결정·코드(텍스트)** | **GitHub**(이 저장소, 브랜치) | 버전관리·diff·이력 |
| **대용량 자산**(.3dm 300MB~3GB·렌더·이미지) | **Google Drive 허브** | Git 부적합(용량) |
| **맥락 앵커**(HANDOFF·DECISIONS) | Git(주) + **Drive 미러** | 어느 기기/세션에서도 즉시 열람 |

> 한 줄: **텍스트는 Git, 자산은 Drive, 맥락은 양쪽에. Drive가 허브.**

## 1. Google Drive 허브 구조

기존 프로젝트 폴더(`가상공연제작_플랫폼/`) 아래 허브를 둔다.

```
가상공연제작_플랫폼/                 (기존)
└── VPP_HUB/                        (데이터 허브 루트)
    ├── 00_CONTEXT/                 # HANDOFF·DECISIONS 미러, 세션 로그
    ├── 10_ASSETS/                  # 3dm 모델·렌더·이미지 (또는 기존 위치 인덱스)
    ├── 20_PLAN_MIRROR/             # GitHub docs 읽기용 미러
    └── 30_WORKING_<OS>/            # 각 기기 작업 임시(win/mac/linux)
```

- 대용량 자산은 *이동하지 않고* `ASSET_INDEX`(파일 위치·ID)로 등록(이동은 위험).
- `00_CONTEXT`의 HANDOFF 미러를 보면 어느 기기에서든 현재 맥락 파악.

## 2. 각 OS 로컬 폴더 & 동기화 도구

| OS | 동기화 도구 | 로컬 경로(예) |
|----|-------------|---------------|
| **Windows** | Google Drive for Desktop | `G:\내 드라이브\...\VPP_HUB` (기존 `G:\Create with Claude`) |
| **macOS** | Google Drive for Desktop | `~/Library/CloudStorage/GoogleDrive-<계정>/내 드라이브/.../VPP_HUB` |
| **Linux** | **rclone**(권장) 또는 Insync | `~/VPP_HUB` (rclone mount/sync) |

- Git은 모든 OS 공통: 각 기기에서 이 저장소 `clone` + 동일 브랜치 사용.
- Drive 동기화 폴더 ≠ Git 작업 폴더(혼선 방지). 자산은 Drive 폴더, 문서·코드는 Git 폴더.

## 3. 크로스-OS 작업 규칙 (충돌 방지)

1. **작업 시작:** ① `git pull` ② Drive 동기화 완료 확인 ③ **HANDOFF.md 읽기**.
2. **작업 종료:** ① 문서·코드 `commit + push` ② 자산은 Drive 동기화 ③ **HANDOFF·
   DECISIONS 갱신·push + Drive 미러 갱신**.
3. **동시편집 금지:** 같은 파일을 두 기기에서 동시에 열지 않는다. 텍스트 충돌은 Git이,
   자산 충돌은 Drive 버전기록이 흡수.
4. **명명:** 자산 버전은 `이름_YYYYMMDD[_설명].확장자`(기존 관행 유지).
5. **단일 활성 기기:** 가능하면 한 시점에 한 기기에서 진행.

## 4. 맥락 연속성 프로토콜 (Context Continuity)

- **세션/기기 시작 읽기 순서:** `HANDOFF.md → DECISIONS.md → 최신 reports/`.
- HANDOFF·DECISIONS는 큰 진전마다 갱신·push + **Drive `00_CONTEXT` 미러 갱신.**
- 컨텍스트 압축(90~95%) 시: HANDOFF 먼저 고정 → 디스크/Git/Drive 3중 보존.

## 5. 즉시 실행 (극장장 처리)
- Drive에 `VPP_HUB/00_CONTEXT` 구성 + HANDOFF·본 문서 미러 + ASSET_INDEX 작성.
- (창시자) 각 기기에 Drive for Desktop / rclone 설치 + 이 저장소 clone.

## 6. 미결 (→ DECISIONS)
- **D44** 자산을 `10_ASSETS`로 *이동* vs *기존 위치 인덱스 유지*(권장: 인덱스).
- **D45** Linux 동기화: rclone vs Insync.
