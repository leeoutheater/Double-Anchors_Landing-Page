> 관객(시민)의 기부금**이다(시민 주권 — [14]). 아래 §2의 기관 구독·공공 사업·

## 0. 핵심 재원 — 시민 기부 + 공공 예산 매개 (Sustainability Portfolio)

> **재정의(2026-06-01, [17] 입장 반영):** 막연한 기부 의존도, 정부 예산 종속도
> 거부한다. **공공 예산(=시민 세금)을 시민·예술가에게 *되돌리는 매개 인프라*** 로서
> 지속한다. 배분 결정은 시민, 통제는 누구도 갖지 않음(독립). 상세: [17].

| 재원 | 위치 | 설명 |
|------|------|------|
| **① 공공 예산 매개·집행** | **중추** | 관료 게이트키핑을 대체하는 투명·민주·책무 인프라로서 공공 예술예산 집행을 매개(운영 매개 비용). **배분은 시민이 결정·통제 이양 없음**([17] §4 방화벽) |
| **② 시민 기부 + 매칭펀드** | **주권 앵커** | 시민 직접 후원으로 주권·정당성, 공공 매칭으로 레버리지 |
| ③ 공공가치 기반 지속 투자 | 인프라 정당화 | 안전·접근성·책무성·참여 등 측정 가치로 공공재 인프라 정당화 |
| ④ 자생 수익 | 보강 | 기관 트윈·검증 SaaS·사용량·교육·아카이브(§2) |

- **운영 주체:** 관객(시민) 섹션(기부·투명 보고) + 공공 섹션(예산 매개·매칭) + 극장장
  (집행 감독)([14]).
- **방화벽:** 조건부(정치 통제·홍보 목적) 자금 거부, 독립성(F22), 전액 공개·감사. ([17] §4)

> 아래 §1~ 은 *자생 수익(④)* 관점의 보강 재원으로 유지한다.

## 1. 가치 제안과 지불 주체 (Who Pays for What)

| 지불 주체 | 무엇에 지불하는가 | 형태 |
|-----------|------------------|------|
| 극장·문화재단 | 입장 작품의 구현가능성·**안전성** 검증, 운영 효율 | 구독/연간 라이선스 |
| 공공기관(정부) | 지원 심사·예산 타당성·성과 추적, 정책 인프라 | 사업비/구축·운영 위탁 |
| 공연단체·예술가 | 시연 제작·지원사업 자료·협업 | 구독/사용량(저가·일부 무료) |
| (간접) 시민 | 향유·예매 | 무료 향유 + 예매는 외부 연계 |

> 핵심: **비용·위험을 가장 크게 지는 측(극장·공공)이 핵심 지불 주체**,
> 예술가·시민은 낮은 장벽으로 참여시켜 생태계를 키운다.

## 2. 수익 모델 (Revenue Streams)

| 모델 | 설명 | 단계 |
|------|------|------|
| **기관 구독/라이선스** | 극장·재단의 트윈·검증·운영 도구 연간 이용 | Phase 1~ |
| **공공 구축·운영 사업** | 공공기관 대상 플랫폼 구축·위탁운영(B2G) | Phase 1~ |
| **창작자 구독** | 예술가·단체의 시연 제작(등급제, 일부 무료) | Phase 1~ |
| **사용량 과금** | 서버 렌더·정밀 시뮬·저장 등 사용분 | Phase 2~ |
| **트윈·에셋 마켓** | 극장 트윈·무대/조명 에셋 공유 중개 | Phase 3~ |
| **예매 연계 수수료** | 외부 예매 연동 시 일부 수수료(선택) | Phase 2~ |

**전략:** 제작·향유는 낮은 장벽(무료/저가)으로 확보, **검증·운영·공공
인프라**에서 매출을 회수. 향유 자체는 공공재로 무료 지향.

## 3. 요금/사업 구조 초안 (가설)

| 구분 | 대상 | 포함 | 과금 |
|------|------|------|------|
| **Creator** | 예술가·단체 | 시연 제작, 기본 검증, 지원사업 자료 | 무료~저가 구독 |
| **Theater** | 극장·재단 | 극장 트윈, 구현/안전 검증, 라이더·대관 | 연간 라이선스 |
| **Public** | 공공기관 | 심사·예산·성과·책무성, 다작품 관리 | 구축/위탁 사업비 |
| **Citizen** | 시민 | 향유·사전 체험·접근성 정보 | 무료 |

> 금액은 PoC 원가 산출 + 기관 지불의향·공공 사업 단가 조사 후 확정.

## 4. 비용 구조 (Cost Structure)

| 비용 | 성격 | 비고 |
|------|------|------|
| 트윈 구축(실측·정규화) | 초기 변동 | 협력 극장당 1회성+갱신 |
| 렌더/시뮬 GPU | 변동 | 작품·정밀도 연동 |
| 스트리밍/CDN | 변동 | 향유 규모 연동 |
| AI API | 변동 | 자막·번역·리뷰 집계 |
| 스토리지 | 변동 | 시연·아카이브 |
| 인건비 | 고정 | 개발·**도메인 검수**·운영·BD |
| 도메인 검수 | 고정 | 안전·규격 정합성(품질 핵심) |

**원가 핵심:** 트윈 구축비를 재사용(여러 작품이 같은 트윈 활용)으로
분산하고, 변동비(렌더·시뮬)는 사용량 과금으로 연결.

## 5. 단위 경제성 (검증 대상)

- **극장 단위:** 트윈 1회 구축 → N개 작품이 재사용할수록 단위비용↓
- **작품 단위:** (창작 구독 + 사용량) − (렌더·시뮬 변동비)
- **공공 사업 단위:** 구축·운영 위탁 매출 − (개발·운영·검수 배분)
- → Phase 0 PoC에서 **트윈 구축비·작품당 인프라 단가** 실측 후 가격 역산

## 6. 공공 가치 = 비재무 성과 (1차 KPI)

> 공공·기관 사업 특성상 초기 성공은 매출보다 **공공 성과·레퍼런스**.

```
북극성 지표: "검증을 거쳐 안전하게 올라가고, 시민이 누린 공연 수"
├─ [안전] 가상시연으로 사전 점검된 작품/공연 수, 발견·개선된 위험 건수
├─ [책무성] 예산 타당성 자료가 활용된 지원 심사·집행 건수
├─ [접근성] 시민 사전 체험 도달·배리어프리 정보 제공 공연 수
├─ [효율] 반복 협의·시행착오 절감(정성+정량)
├─ [채택] 협력 극장·참여 기관 수, 재계약/재사용률
└─ [지속] 기관 구독·공공 사업 매출(2차)
```

## 8. Go-to-Market

1. **앵커 극장 파일럿:** 1~3개 협력 극장 트윈 구축 → 실제 1편 완주 레퍼런스
2. **공공 정합성:** 안전·책무성·접근성 정책 부합을 전면에, 공공 사업 진입
3. **창작자 저변:** 예술가 무료/저가로 시연 저변 확대 → 작품 공급
4. **시민 향유 공개:** 무료 사전 체험으로 사회적 가시성·정책 지지 확보
5. **확장:** 검증된 모델을 다극장·다기관·지역 재단으로 복제
