# 가상공연제작 웹플랫폼 (Virtual Performance Production Platform)

> 누구나 웹 브라우저에서 가상공연을 기획·제작·송출·수익화할 수 있는 클라우드 기반 제작 스튜디오.

이 저장소 폴더는 **신규 독립 사업**의 기획 초안을 담고 있습니다. 본 기획안은
구글 드라이브에서 진행 중인 가상공연제작 플랫폼을 대폭 수정·재정의하기 위한
기준 문서로 사용합니다.

---

## 📌 한 줄 정의

설치 없이 웹에서, AI 보조를 받아, 가상 무대·아바타·라이브 송출까지 하나의
워크플로우로 끝내는 가상공연 제작 SaaS.
