# 공연예술 가상시연 통합 플랫폼 (Virtual Pre-visualization Platform for Performing Arts)

> 공연자·극장·공공기관·시민을 잇고, 공연을 실제로 올리기 전 **가상시연**으로
> 검증하여, 기획부터 제작·운영·시민 향유까지 하나로 잇는 통합 플랫폼.

이 폴더는 **신규 독립 사업**의 기획 초안을 담는다. 본 기획안은 구글 드라이브
에서 진행 중인 가상공연제작 플랫폼을 대폭 수정·재정의하기 위한 기준 문서다.

---

## 📌 한 문장 정의

가상으로 공연을 *대체*하는 것이 아니라, 실연(實演)을 *더 잘 올리기 위해
미리 시연·검증*하고, 그 결과를 *시민 향유*로 잇는 공연예술 통합 플랫폼.

## 🎯 핵심 구조

- **연결 4주체:** 공연자(예술가) · 극장운영자(문화재단) · 공공기관(정부) · 관객(시민)
- **검증 4축:** ①작품성×대중성 ②구현가능성×안전성 ③기획·예산 타당성 ④홍보 기반
- **통합 생애주기:** 기획 → 제작 → 운영 → 향유
